Приложение для управления списком контактов устройства, объединяющее функции просмотра, осуществления вызовов и автоматического удаления дубликатов через изолированный сервис.

## Технологии и стек

* **UI**: Jetpack Compose 
* **Архитектура**: Clean Architecture, MVVM
* **DI**: Dagger Hilt
* **Async**: Kotlin Coroutines & Flow
* **IPC**: AIDL (Android Interface Definition Language) 
* **Data**: ContentResolver

## Реализованный функционал

Проект выполнен в соответствии с требованиями Вариантов 1, 3 и 4 технического задания:

1. **Список контактов (Вариант 1/3)**: Отображение данных о контактах, сохраненных на устройстве, в виде списка с группировкой по алфавиту и краткой информацией о каждом записи.


2. **Звонки (Вариант 1)**: Реализована возможность совершения вызова на мобильный номер контакта по нажатию на пункт списка (использование `Intent.ACTION_CALL`).


3. **Дедупликация (Вариант 3)**: Поиск и удаление контактов, имеющих полностью одинаково заполненные поля.


4. **AIDL Service (Вариант 2/3)**: Все операции с контактами (чтение, поиск дубликатов, удаление) реализованы внутри отдельного сервиса `ContactsService`, который взаимодействует с основным приложением через AIDL интерфейсы.


5. **Информирование**: Реализована система уведомлений пользователя о статусе операций: начало процесса, успешное удаление, отсутствие дубликатов или возникновение ошибки.


6. **Алгоритм (Вариант 4)**: Реализован алгоритм выборки сотрудников-юбиляров на текущую неделю. Код написан на языке Kotlin.



## Инструкция по запуску

1. Склонируйте репозиторий.
2. Дождитесь завершения синхронизации Gradle.
3. Для корректной работы приложения необходимо предоставить разрешения на чтение и запись контактов, а также на осуществление звонков.
4. Проверка алгоритма юбилеев (Задание 4) доступна через запуск функции `main` в файле `JubileeCalculator.kt`.
